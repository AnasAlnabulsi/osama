# Proxmox Server – aktueller dokumentierter Ist-Zustand

Stand: 22.09.2026

Dieses Verzeichnis bildet den erfassten aktuellen Zustand des Proxmox-Hosts und der VM 102 `DockerStack` ab.

- `proxmox/etc/`: anwendbare Host-/Proxmox-Konfigurationen
- `proxmox/inventory/`: vollständige beobachtete Host-, Hardware- und Runtime-Fakten
- `vm102/etc/`: Ubuntu-Systemkonfiguration
- `vm102/docker/`: Docker-/Anwendungskonfiguration
- `vm102/inventory/`: beobachtete VM-/Docker-Runtime-Fakten
- `docs/`: sortierte Dokumentation
- `scripts/`: read-only Inventarisierung

Secrets, echte `.env`-Werte, Datenbankdaten und private TLS-Schlüssel sind nicht enthalten.
